Make Claude Code Talk Back: A Free Voice and a Desktop Robot

One copy-and-paste prompt gives Claude Code a natural voice that reads its replies out loud, plus a cute little robot on your screen. Tap it to pause Claude. Tap it to talk to Claude. Free, and it runs on your own computer.

The real thing: talking to Claude Code hands-free while the robot reads its answers out loud.

Get the guide and prompt as a PDF FREE

Save it, print it, or send it to a friend who lives in Claude Code.

If you already talk to Claude Code instead of typing, you know the catch: it only ever writes back. Every reply means stopping what you're doing to read the screen.

This setup fixes that. When Claude finishes a task, a small robot pops up on your screen and reads the answer out loud. You can get up, make a coffee or work on something else, and still hear exactly what got done. And when you want to say something, you tap the robot, talk, and tap again to send.

What you get

A voice for ClaudeThe start of every reply is read out loud in a natural voice that runs on your own PC.
A robot on your screenIt floats over every window, bounces while Claude talks and blinks while it waits.
Tap to pauseTap while Claude is talking to pause it. Tap again to carry on.
Tap to talkTap when it's quiet, say your message, tap again. It goes straight into Claude Code.

Why it's worth it: you stop being tied to the screen. Claude keeps working while you do something else, and you hear the result the moment it's ready.

What you need

  • A Windows 10 or 11 computer
  • VS Code with the Claude Code extension, already set up and working
  • A microphone and speakers (headphones are best, see the tip below)
  • About 1 GB of free space for the free voice and speech-to-text downloads. Claude Code sets up anything else it needs, such as Python, and asks you first.

The prompt

This prompt includes the lessons we learned building it, so Claude gets it right first time: going quiet while you talk (so there's no echo), a cancel button, and jumping back to the app you were in after sending.

Paste into Claude Code
Build me a talking desktop robot for Claude Code. Work through it in stages, test each stage before moving on, and ask me before installing anything.

**What I want**
1. **Claude talks back.** Every time you finish a reply in the Claude Code panel in VS Code, the start of your reply is read out loud with a free, natural-sounding voice that runs entirely on my computer. No paid voice service and no API key.
2. **A little robot on my screen.** A cute pixel-art robot (a small orange block with two eyes, little arms and four legs) floats on top of all my windows in the bottom-right corner. It bounces in time with your voice while you talk and blinks now and then.
3. **Tap the robot to control you.** While you're talking: tap to pause, tap again to resume, or tap a small red ✕ on the robot to stop talking completely. While you're quiet: tap to start listening, I talk, I tap again, and my words get typed into the Claude Code chat box and sent.

**How to build it (decisions already made, please follow them)**

*Voice*
- Use Kokoro through the `kokoro-onnx` Python package. Download `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the kokoro-onnx project's GitHub releases. Play me a few voice samples first so I can pick one. British voices need `lang="en-gb"`.
- Put everything in its own folder with its own Python virtual environment (for example `%USERPROFILE%\.claude\voice\`).
- Add a **Stop hook** to `~/.claude/settings.json`. The hook reads `last_assistant_message` from the JSON on stdin (fall back to the last assistant text in `transcript_path`), keeps only the **first paragraph**, strips markdown, links and URLs, caps it at about 1,000 characters (cut at the last full sentence), and hands it to the robot. Only speak when `CLAUDE_CODE_ENTRYPOINT` is `claude-vscode`, so headless and scheduled runs stay silent. A file called `muted` in the folder should switch the voice off.
- From then on, write the first paragraph of every reply as natural spoken language: the actual answer, no code, no file paths.

*Robot app (one Python script that stays running)*
- Keep the Kokoro model loaded in memory so replies start in about a second. Split the text into sentences and start playing the first sentence while the rest are still being generated.
- Play audio through a `sounddevice` output stream fed from a queue, so pause and resume are instant. Measure the loudness of each audio block and use it to drive the bounce.
- Window: `tkinter`, borderless (`overrideredirect`), always on top, with a transparent colour key so only the robot shows. Draw the robot on a canvas from rectangles on a grid, with a white sticker outline. Redraw only when something changes.
- Faces: happy `> <` eyes while talking, closed eyes when paused, open square eyes when idle, big eyes plus a blinking red dot when listening, and eyes looking up while waiting for my words.
- Listen on a local socket (127.0.0.1 only) for JSON commands such as `say`, `stop` and `toggle`. The hook sends text there, and starts the robot first if it isn't running.
- Dragging moves the robot, but keep it inside the screen's work area so it can't get lost behind the taskbar. Only treat a click as a tap if the mouse barely moved.
- While you're talking or paused, show a small red ✕ at the robot's top-right corner. Tapping the ✕ stops the reply completely; tapping anywhere else on the robot pauses or resumes.
- Right-click menu: Stop talking, Cancel recording, Replay last answer, Minimize to taskbar, Hide until you next talk, Quit.
- Minimize to taskbar: a borderless window can't sit in the taskbar, so switch borders on, `iconify()`, and switch them off again when the window is restored (catch the `<Map>` event). Give it its own taskbar icon (a tiny pixel copy of the robot) and call `SetCurrentProcessExplicitAppUserModelID` so it doesn't group under Python.
- Add a Startup-folder shortcut and a Start Menu shortcut ("Claude Robot") that run it with `pythonw.exe`, so there's no console window.

*Tap-to-talk*
- Record the microphone with `sounddevice` at 16 kHz and transcribe it locally with `faster-whisper` (`small.en`, using the GPU if available, otherwise the CPU). Pass a short vocabulary list (Claude, Claude Code and any names I use) as `initial_prompt` so names are spelled right.
- While listening, show a small red ✕ on the robot. Tapping the ✕ throws the recording away and sends nothing.
- **While the mic is on, pause your voice and hold any new reply until I've finished.** Otherwise the mic records you, and you end up in my message and on my screen recordings.
- To send: find the VS Code window (title ends with "Visual Studio Code"), bring it to the front (use the `AttachThreadInput` trick so Windows allows it), put the cursor in the Claude chat box, paste the text from the clipboard, press Enter, then put my old clipboard back.
  - To focus the chat box, add a keybinding to VS Code's `keybindings.json`: `{ "key": "ctrl+alt+shift+f9", "command": "claude-vscode.focus" }`, and have the robot press it. Don't use Ctrl+Esc, because it toggles focus away when the box is already focused.
  - Remember which app I was in before I tapped, and switch back to it straight after sending, so VS Code only flashes up for about a second.

**Testing**
- After each stage, show me proof that it works, such as a log line, the measured time to first sound, or a check of the window's position and size. Keep a small log file with timings and errors.
- Don't send test messages into my chat without asking me first.

**Privacy**
The voice and the speech-to-text both run on my computer. My messages to Claude still go to Anthropic as usual. Nothing else leaves my machine.

Frequently asked questions

Does it cost anything?

No. The voice (Kokoro) and the speech-to-text (Whisper) are free and run on your own computer. You only need the Claude plan you already use for Claude Code.

Does it work on a Mac?

The prompt is written and tested for Windows. Kokoro itself runs on a Mac, but the robot window and the typing into VS Code use Windows-only features, so a Mac needs a different version of the prompt.

Is my data private?

The voice and the speech-to-text both run on your own computer, so Claude's replies are never sent to a voice company and your recordings never leave your PC. Your messages to Claude still go to Anthropic, exactly as they do when you type.

Can I change the voice?

Yes. Kokoro comes with dozens of voices. Ask Claude Code to play you samples and switch to the one you like.

What if the robot disappears?

Press the Windows key, type "Claude Robot" and press Enter. It also starts again by itself on Claude's next reply and every time you log in.
